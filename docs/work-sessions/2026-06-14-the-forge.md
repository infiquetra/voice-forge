### Key execution decision — Lit dropped, vanilla custom elements adopted

The plan (KTD1/KTD10) named Lit as the component library. At build time, vendoring Lit as a self-contained offline file proved impossible without a bundler: `cdn.jsdelivr.net/npm/lit@3/+esm` (541 B) and `esm.sh/lit@3?bundle` (137 B) both return **re-export wrappers that chain to network URLs at runtime** — a hidden network dependency that breaks the hard "ships-ready / runs-offline / no-build" rule (R23). A self-contained single file requires running a bundler — the exact build step the architecture forbids.

Resolution: **vanilla custom elements** (`ForgeElement` base, ~50 lines) — zero dependency, browser-native, nothing to vendor. This is within the settled "no-build Web Components" decision (the operator endorsed *Web Components*; Lit was the ergonomic add-on) and is explicitly sanctioned by the plan's KTD1 ("plain `customElements.define` for zero dependencies, or Lit"). It *strictly better* honors the core requirement. Carry into a DECISIONS.md note at phase close.

**Security convention (from the PostToolUse XSS warning):** all registry/user-derived strings (voice ids, personas, descriptions) MUST be routed through `esc()` before interpolation into `render()` templates. The code-review gate enforces this.

### First browser run — two real bugs caught + fixed ✓ (commit `39fa39f`)

Served `/forge` and drove it in a browser (`mcp__Claude_Preview`) instead of asserting it worked. Two runtime bugs that all-green `node --check` + pytest had missed:

1. **API contract mismatch** — both list endpoints answer with an OpenAI-style `{data:[…]}` envelope (`VoiceInfo.id`, `BackendInfo.{name,installed,is_default,tunables}`); the client assumed `{voices}`/`{backends}` and stored the envelope object. The empty dev registry (`{data:[]}`) masked it. Fixed with one `asList()` normalizer at the `_load` boundary.
2. **Playback self-destruct** — `forge-waveform` wrote `store.forging` on play; the card + shell observe `forging` and replace their `innerHTML`, destroying the playing chip instantly. Fixed: playback is local; `forging` dropped from the shell's observe.

Both locked by regression guards. Full write-up: [LEARNINGS 2026-06-14](../engineering-journal/LEARNINGS.md). Residual full-re-render cost → [QUEUED P2](../engineering-journal/QUEUED.md).
