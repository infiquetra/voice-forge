# Engineering Journal — Narratives

Long-form companion docs to the LEARNINGS / DECISIONS / QUEUED / ARCHIVE entries.

One file per topic; filename pattern `YYYY-MM-DD-topic.md`.

When you write a narrative, link to it from the LEARNINGS / DECISIONS entry that surfaced it. Narratives capture the "why" and "how it came together" that doesn't fit in an entry's structured fields.
